## Deploy updates to your existing GitHub Pages repository

1. **Back up** the current `portfolio` folder on your computer.
2. In your cloned `portfolio` Git repository, **keep the hidden `.git` folder**.
3. Remove the other old website files and folders from the repository root; copy **all contents** of this curated package into that root.
4. Confirm `index.html`, `styles.css`, `script.js` and `assets/` are at the root, not inside a nested folder.
5. Open `index.html` locally and test both language buttons and each project page.
6. GitHub Desktop: commit with `Curate portfolio for job applications`, then **Push origin**.
7. GitHub Pages should remain configured to `main` / `(root)`.

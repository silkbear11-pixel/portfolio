- `original-des117/` and `original-des157a/` — Archived class projects

## Local preview

Open `index.html` in a browser. For the most reliable behavior when reviewing local assets and interactive projects, serve the folder with a local web server.

## GitHub Pages publishing

Copy the **contents** of this folder into the root of the `portfolio` repository so `index.html` is at the top level. Commit and push changes to `main`. Configure GitHub Pages for branch `main`, folder `/ (root)`.
